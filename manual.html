01このアプリについて

できることと、できないことを最初に整理します。

「ちょい便」は、同じネットワークにつながった端末同士でファイルを直接やりとりするアプリです。クラウドにもアカウントにも頼らないので、データが社外のサーバーを経由することはありません。

できること

やりたいこと方法
Windows → Windowsアプリ同士が自動で見つけ合います。相手を選んで送るだけです
iPhone / Android → WindowsPC の QR コードを読んで、ブラウザーでファイルを選びます。アプリのインストールは要りません
Windows → iPhone / AndroidPC でファイルを公開し、スマホのブラウザーから保存します

できないこと

Mac や iPhone の AirDrop に直接送ることはできません

AirDrop は AWDL という Apple 独自の無線方式を使っています。仕様が公開されておらず、対応するのは Apple 製の Wi-Fi チップだけです。「Windows で AirDrop」をうたう市販ソフトも、実際には AirDrop につないでいるのではなく、同じネットワーク上での独自転送を行っています。「ちょい便」も同じ方針で、同じ使い心地を別の仕組みで実現しています。

そのため、相手の Mac や iPhone に送りたい場合は、4 章のブラウザー経由の方法を使ってください。相手側にアプリを入れる必要はありません。

02準備する

ビルドから初回起動まで。ここでつまずくとしたら、ほぼファイアウォールです。

必要なもの

  • Windows 10 バージョン 1809 以降、または Windows 11
  • Visual Studio 2022（「.NET デスクトップ開発」ワークロード）
  • .NET 8 SDK

外部の NuGet パッケージは一つも使っていません。ネットワークにつながっていない環境でもそのままビルドできます。

ビルドする

  1. Choibin.sln を Visual Studio で開く
  2. F5 を押すビルドだけなら Ctrl+Shift+B です。

コマンドラインから実行する場合:

dotnet build Choibin.sln -c Release
dotnet run --project src/Choibin/Choibin.csproj

初回起動とファイアウォール

「プライベート ネットワーク」にチェックを入れて許可してください

初めて起動すると Windows Defender ファイアウォールの確認画面が出ます。ここで拒否すると、相手の一覧にあなたの PC が出てこなくなります。

あとから許可し直したい場合や、確認画面を見逃した場合は、同梱の ファイアウォール許可.bat を右クリックして「管理者として実行」してください。必要な 3 つのポートをまとめて開けます。

2 台目以降

送る側と受け取る側の両方に「ちょい便」が必要です。同じ手順でビルドして起動してください。ビルド済みの Choibin.exe をフォルダーごとコピーしても動きます。

03PC 同士で送る

いちばん基本の使い方です。

  1. 両方の PC で「ちょい便」を起動する同じ Wi-Fi、または同じ有線 LAN につないでおいてください。
  2. 相手が出てくるのを待つ数秒で、画面左の「近くのデバイス」に丸いアイコンが並びます。背景の同心円は、相手を探している間だけゆっくり脈打ちます。
  3. 送るファイルを用意する中央の枠にドラッグ＆ドロップするか、枠をクリックして選びます。複数まとめて指定できます。
  4. 相手のアイコンをクリックして選ぶ選ぶと青い枠がつきます。
  5. 「選んだデバイスへ送る」を押す
  6. 受け取る側で「はい」を押す確認画面には、ファイルの一覧・合計サイズ・保存先、そして確認コードが表示されます。

転送中の進み具合は、画面中央下の「やりとりの記録」に出ます。完了すると保存先のパスが表示されます。

毎回の確認が面倒なとき

設定の「確認せずに自動で受け取る」にチェックを入れると、確認画面なしで保存されます。自席の PC 同士など、相手が確実に分かっている場合だけにしてください。

04スマホとやりとりする

スマホ側にアプリは要りません。ブラウザーだけで完結します。

スマホから PC へ送る

  1. スマホを PC と同じ Wi-Fi につなぐ
  2. PC の画面右側にある QR コードを、スマホのカメラで読むiPhone なら標準のカメラアプリで読み取れます。
  3. 証明書の警告が出たら「詳細」から進む初回だけです。理由は7 章で説明します。
  4. 「ファイルを選ぶ」をタップする選んだ瞬間に転送が始まり、PC の受信フォルダに保存されます。

PC からスマホへ送る

  1. PC でファイルをドロップする
  2. 「スマホに公開」を押す
  3. スマホのページを開く（または再読み込みする）ページの下側にファイルが並びます。
  4. ファイル名をタップして保存する
ホーム画面に追加できます

iPhone の共有メニューから「ホーム画面に追加」を選ぶと、アプリのように起動できます。ただしアクセスキーは「ちょい便」を再起動するたびに変わるため、そのたびに QR コードを読み直す必要があります。

05画面の見方

ウィンドウは 3 つの列に分かれています。

左: 近くのデバイス

見つかった相手が丸いアイコンで並びます。頭文字と IP アドレスが出ます。16 秒間応答がない相手は自動的に消えます。「もう一度探す」で即座に探し直せます。

中央上: 送るファイル

ドロップした（または選んだ）ファイルの一覧です。ここに入れてから送り先を選びます。

中央下: やりとりの記録

送信・受信の履歴と進捗です。鍵マーク 🔒 は暗号化されている印で、マウスを乗せると確認コードが出ます。

右: スマホ連携と設定

QR コード、接続先の URL、各種設定、受信フォルダの変更がまとまっています。

このPCの名前

画面右上のテキストボックスで変更できます。ここで付けた名前が、相手の一覧に表示されます。初期値は Windows のコンピューター名です。入力欄からフォーカスを外した時点で保存され、すぐ相手に伝わります。

06設定

画面右側にまとまっています。変更するとすぐ保存されます。

項目説明
スマホからの接続を受け付ける 外すとスマホ向けのページが停止し、QR コードも消えます。PC 同士のやりとりには影響しません。
確認せずに自動で受け取る 受信時の確認画面を省きます。届いたファイルは黙って受信フォルダに保存されます。
送信前に確認コードを見比べる 送る直前に確認コードのダイアログを出します。相手の画面と数字を見比べてから送りたいときに使います。
スマホとの通信も HTTPS にする 初期値はオンです。外すと通信が暗号化されなくなる代わりに、ブラウザーの警告は出なくなります。
受信フォルダ 初期値は %UserProfile%\Downloads\Choibin です。「変更」で移せます。同名のファイルが既にある場合は自動で連番が付きます。

設定は %AppData%\Choibin\settings.json に保存されます。このファイルを消せば初期状態に戻ります。

07安全のしくみ

何がどう守られているのかを説明します。

PC 間の転送は必ず暗号化されます

設定で切ることはできません。接続するたびに、その場かぎりの鍵を作って交換します。

段階使っている技術
鍵交換ECDH（楕円曲線 P-256）。公開鍵だけをやりとりし、鍵そのものは回線に流れません
鍵の導出HKDF-SHA256。送る向きと受け取る向きで別々の鍵を作ります
本体の暗号化AES-256-GCM。64 KiB ごとのかたまりに分けて暗号化します

鍵は接続が終わると捨てるので、通信を記録しておいて後から解読することはできません。またデータには連番が混ぜてあり、並べ替え・欠落・再送・改ざんはすべてエラーとして弾かれます。

確認コード

鍵交換だけでは、間に入った第三者が両側と別々に鍵を交換する「中間者攻撃」を防げません。そこで共有した秘密から 6 桁の数字を作り、受信の確認画面に表示しています。

送る側と受け取る側で同じ数字なら、間に誰もいません

違う数字が出ている場合は転送をやめて、ネットワークの管理者に相談してください。送信側でも確認したい場合は、設定の「送信前に確認コードを見比べる」を入れてください。

スマホとの通信

初期状態では HTTPS（TLS 1.2 / 1.3）で待ち受けます。ただし、LAN 内のプライベート IP アドレスに対しては認証局が証明書を発行してくれないため、証明書はアプリが自分で作っています。これがブラウザーの警告が出る理由です。

警告が出ても、通信は暗号化されています

警告が言っているのは「この証明書が本物だと保証してくれる第三者がいない」ということで、「暗号化されていない」という意味ではありません。「詳細」→「アクセスする」で進んでください。証明書は PC の IP アドレスが変わったときだけ作り直されます。

アクセスキー

スマホ向けのページには、起動のたびに作られる 8 文字のキーが必要です。QR コードにはキーが埋め込んであるので、読み取った端末はそのまま開けます。同じ Wi-Fi にいる別の人が URL を打ち込んでも入れません。アプリを再起動するとキーは変わります。

08困ったとき

よくある症状から探してください。

相手の PC が一覧に出てこない

上から順に確認してください。

  1. ファイアウォール — もっとも多い原因です。両方の PC で ファイアウォール許可.bat を管理者として実行してください。
  2. 同じネットワークか — 一方が 5GHz、他方がゲスト用 SSID につながっていると届きません。PC の IP アドレスの上 3 つの数字が揃っているか見てください。
  3. ネットワークの種類 — Windows の設定でネットワークが「パブリック」になっていると通信が制限されます。「プライベート」に変更してください。
  4. ゲスト Wi-Fi — カフェやホテルなど、端末同士の通信が遮断されているネットワークでは原理的に見つけられません。
  5. それでも出ない場合は「もう一度探す」を押してください。
「相手に接続できませんでした（応答なし）」と出る

一覧には出ているのに接続できない場合、受け取る側のファイアウォールで TCP 53318 がふさがれている可能性が高いです。受け取る側で ファイアウォール許可.bat を実行してください。相手が転送中にアプリを閉じた場合にも出ます。

スマホのブラウザーで「この接続ではプライバシーが保護されません」と出る

自己署名証明書を使っているため、初回に必ず出ます。異常ではありません。「詳細設定」→「アクセスする」（iPhone なら「詳細」→「この Web サイトを閲覧」）で進んでください。どうしても警告を出したくない場合は、設定の「スマホとの通信も HTTPS にする」を外してください。ただし通信は暗号化されなくなります。

スマホで「アクセスキーが必要です」と出る

PC 側で「ちょい便」を再起動すると、アクセスキーが変わります。ブックマークや履歴から開くと古いキーのままなので弾かれます。PC の画面に出ている QR コードを読み直してください。

送信側と受信側で確認コードが違う
転送を中止してください

通信の間に第三者が入り込んでいる可能性があります。信頼できるネットワークにつなぎ直したうえで、ネットワークの管理者に状況を伝えてください。

「受信データの検証に失敗しました」と出る

暗号化されたデータの整合性チェックに失敗しています。通信が途中で壊れたか、改ざんされた可能性があります。無線が不安定なだけのこともあるので、まずは電波の良い場所で送り直してください。繰り返し出る場合は有線 LAN を試してください。

QR コードが表示されない / 「起動できませんでした」と出る

ポート 53319 を他のアプリが使っている可能性があります。コマンドプロンプトで netstat -ano | findstr 53319 を実行すると、使用中のプロセスが分かります。ポートを変えたい場合は src/Choibin/Core/AppSettings.cs の定数を書き換えてビルドし直してください。

フォルダーを送ったら中身が一部しか届かない

現在の版では、フォルダーをドロップしても直下のファイルだけが対象になります。サブフォルダーの中までは辿りません。丸ごと送りたい場合は、あらかじめ ZIP にまとめてください。

設定%AppData%\Choibin\settings.json

現時点の制限

  • IPv4 のみに対応しています
  • フォルダーは直下のファイルだけが対象です（再帰しません）
  • 相手が本人かどうかは、確認コードを目で見比べる方式です。一度確認した相手を覚えておく仕組みはありません
  • スマホ向けの証明書は自己署名のため、ブラウザーの警告を一度受け入れる必要があります
  • 端末同士の通信が遮断されたネットワークでは相手を検出できません

10よくある質問

Mac の AirDrop に直接送れませんか？

できません。AirDrop が使っている AWDL は仕様が公開されておらず、Apple 製の Wi-Fi チップ専用です。Mac に送りたい場合は、Mac の Safari で QR コードの URL を開いてください。ブラウザー経由なら問題なくやりとりできます。

Bluetooth では使えませんか？

技術的には可能ですが、速度が実用に耐えません。Bluetooth Classic の実効速度は 1〜2 Mbps 程度で、1 GB のファイルに 2 時間近くかかります。Wi-Fi なら 1 分前後です。加えて事前のペアリングが必要で、iPhone は Apple 以外のアプリに接続方式を開放していないため、iPhone とはそもそも通信できません。

ただし「相手を見つける」用途としては有効です。AirDrop 自身がこの構成で、Bluetooth LE で相手を見つけ、実際のデータは Wi-Fi で飛ばしています。この方式を採り入れれば、Wi-Fi につながっていなくても近くの PC を一覧に出せるようになります。

暗号化を切って速くできませんか？

切る手段は用意していません。AES-256-GCM は最近の CPU なら専用命令で処理されるため、実際の転送速度はネットワークの速さで決まります。暗号化が理由で遅くなることはまずありません。

インターネット越しに使えますか？

できません。同じネットワークの中だけで動く設計です。相手を見つける仕組みがブロードキャストに依存しているため、ルーターを越えると届きません。

会社で配布してもいいですか？

社内で使う分には、商標登録などの手続きは要りません。他人の登録商標を製品名として使っていなければ問題にならないためです。「ちょい便」という名前は、Apple の AirDrop をはじめとする既存の商標を避けて選んでいます。

社外に配布・公開する場合は事前に確認を

J-PlatPat で「チョイビン」を称呼検索し、第 9 類（ダウンロード可能なソフトウェア）と第 42 類（ソフトウェアの設計・SaaS）に登録済みまたは出願中の商標がないか確認してください。判断に迷う場合は弁理士にご相談ください。

ポート番号を変えたい

src/Choibin/Core/AppSettings.cs の先頭にある DiscoveryPort / TransferPort / WebPort を書き換えてビルドし直してください。やりとりする全部の PC で同じ値にする必要があります。ファイアウォール許可.bat の中のポート番号も合わせて変えてください。
